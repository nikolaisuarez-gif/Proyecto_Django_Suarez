# Laboratorio 13 — Estructura de comercio electrónico

- `Informe_Laboratorio_13.pdf`: memoria de desarrollo con evidencias, casos de prueba y conclusiones.
- `../../capturas/lab13_catalogo.png`: catálogo completo con ocho productos.
- `../../capturas/lab13_filtro_categoria.png`: resultado del filtro dinámico de categoría.

## Reproducir

Seguir los comandos de instalación del apartado Laboratorio 13 del README principal. Cargar datos con `python todoproject/manage.py seed_catalog`, iniciar Django en el puerto 8000 y el cliente Vite en el 5173. Pruebas: `python todoproject/manage.py test catalog`. Build de producción: `npm run build` desde `client/`.
